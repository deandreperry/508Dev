WCAG 2.2 · SC 2.5.8 · Level AA

Target Size (Minimum)

Learn the minimum, experience the precision problem, repair the target, and test the result without confusing WCAG AA, WCAG AAA, and platform guidance.

  1. Learn

    SC 2.5.8 uses a 24 × 24 CSS pixel minimum for pointer targets. A smaller target can still conform through a spacing, equivalent-control, inline, user-agent-control, or essential-presentation exception.

  2. Experience

    Try activating each control with touch, a trackpad, or a mouse. The demonstration communicates state with text and borders as well as color.

    Potential failure: undersized with insufficient spacing

    Passes the size requirement

  3. Why it fails

    Small, crowded targets demand more pointer precision and can create accidental activations. The left example is not an automatic failure in every context: the relevant exceptions must still be evaluated.

  4. Fix and inspect the code

    <button class="action">Save changes</button>

.action {
  min-inline-size: 44px;
  min-block-size: 44px;
}

    A 44 × 44 CSS pixel target also meets SC 2.5.5 Target Size (Enhanced), Level AAA; it corresponds to the AAA criterion rather than exceeding it. Platform guidance may recommend other values in platform-specific units.

  5. Test it

    • Measure the rendered target area in CSS pixels at the default zoom.
    • When a target is smaller than 24 × 24 CSS pixels, evaluate every defined exception rather than failing it automatically.
    • Test crowded controls with touch, mouse, stylus, keyboard, zoom, and a narrow viewport.
    • Confirm focus indicators and accessible names separately; target size does not cover them.

  6. Assistive-technology notes

    Target size primarily concerns pointer operation. Browser, operating-system, switch-control, voice-control, and assistive-technology behavior can vary. Record the environment and observed result in the testing matrix.
